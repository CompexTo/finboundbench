## Distinct contribution to protect

Do not claim that purpose-based access control or intent-aware agent authorization is new. The proposed contribution is narrower:

1. a finance-specific benchmark where the same principal may access all fields but may use only purpose-authorized fields;
2. paired counterfactual tests that detect silent influence rather than only access or disclosure;
3. an evaluation of prompt, output-only, prefilter and purpose-bound execution controls;
4. auditable execution evidence tied to the purpose contract and financial decision.
