## 1. What this release is

Public, competition-facing release of the FinBoundBench research program:

- **Paper**: 8-page anonymous archival paper (ICAIF 2026 main track),
  compiled in `paper/` from source.
- **Competition**: 4-page ICAIF 2026 competition-track proposal + the full
  starter kit (harness, baselines, sample submission, rules, schema).
- **Benchmark**: frozen protocol v4 artifacts (manifests, statistics,
  findings report, evidence), readable and independently verifiable.
- **Reproducibility**: `make reproduce` runs the full verification pipeline
  with no API key; `make rerun-live` optionally re-executes live lanes with
  `OPENROUTER_API_KEY`.

The release branch is **curated**: it contains the public surface only.
Internal/company artifacts (`.env`, credentials, internal mapping docs,
v2/v3 exploratory results trees, test doubles) stay out.

## 4. Reproduce story

- `make reproduce` — no API key: rebuilds every statistic and check from the
  frozen raw events and manifests (17/17 verification bundle checks,
  independent-stats crosscheck), regenerates the findings report and
  figures, and compiles paper + proposal PDFs.
- `make rerun-live` — optional: re-executes the primary/replication lanes
  against the registered routes with `OPENROUTER_API_KEY`; results are
  labeled `EXPLORATORY` (the frozen confirmatory estimates are never
  overwritten).
- Competition starter kit: `make starter-kit` regenerates the dev leaderboard.

## 7. Push (exact command, requires credentials)

The repository currently has **no git remote configured** and **no `gh` CLI**
on this machine. Once the user provides a remote (or a `gh` install):

```bash
git remote add origin <REMOTE_URL>        # e.g. https://github.com/<org>/finboundbench.git
git push -u origin release/finboundbench-icaif26
git push origin finboundbench-icaif26-v1.0
```

Do not push from any other branch. If credentials are still unavailable at
handoff, the branch + tag remain local and this file is the exact handoff
instruction.
