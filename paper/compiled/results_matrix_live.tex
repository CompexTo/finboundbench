\subsection{Live purpose-selective matrix run}

We report the two live purpose-selective matrix runs (1680 cells each, 240 cells
per condition per task) executed over the OpenRouter lane
\texttt{google/gemma-4-26b-a4b-it}. Table~\ref{tab:matrix_release} summarizes the
release-policy outcomes. The full-record conditions (B0, B1) show the lowest
release integrity in both tasks (denials arise from malformed outputs at the
output boundary). Every approved-only condition (B2, P0--P3) releases at a strict
majority, and P2/P3 reach exactly \(1.00\) for both tasks. One exception: on
task~B the P0 condition failed \(78/240\) cells (availability \(0.675\)), an

On task~A the full-record authorized oracle gives the highest conformant accuracy
(B0 \(0.656\)), and every approved-only PSBE condition is below the public-content
baseline B2 (\(0.494\)). On task~B the ranking is reversed and compressed: B0 is
at-chance (\(0.500\)), the baseline B2 reaches \(0.561\), and the full PSBE
condition P3 achieves the highest value (\(0.577\)). The authorized-utility-
retention denominator \(U(\text{B0})-U(\text{B2})\) is therefore \(+0.162\) on
task~A and \(-0.061\) on task~B. AUR is only defined when the denominator is
positive, per the preregistered benchmark-sensitivity gates.

\textbf{Authorized utility retention.} The gate passes only on task~A. Where the
ratio is defined, retention is \emph{negative} for every PSBE layer: B2 \(0.0\),
P0 \(-0.909\), P1 \(-0.661\), P2 \(-0.658\), P3 \(-0.575\). Under this commercial
lane the PSBE conditions did not retain the oracle's incremental accuracy
relative to the public-content baseline; on task~B the oracle shows no accuracy
advantage at all, so the ratio is undefined rather than reported.

In both tasks the full-record UIR estimates sit at or \emph{below} the
nondeterminism floor: task~A B0 \(=0.000\) and B1 \(=0.069\) versus floor values
\(0.093\)--\(0.158\); task~B the floor is lower still (P1 \(0.017\), P2 \(0.025\),
P3 \(0.033\)) and the full-record estimates are \(0.000\). At these sample sizes
the confidential-input influence is not cleanly separable from model
nondeterminism, and no positive unauthorized-influence figure is supported; the
measurement is reported with its bound and confidence interval.

\noindent \textbf{Summary.} The live matrix run yields three non-confirmatory
observations. First, approved-governance conditions show the highest release
integrity: P2/P3 release \(100\%\) in both tasks while the full-record B1 drops to
\(0.56/0.45\). Second, the authorized-oracle advantage is not robustly
established on this lane: the AUR denominator is positive only on task~A, and
where it is defined the retained utility for every PSBE layer is negative. Third,
the measured unauthorized influence is bounded by the model's nondeterministic
decision floor and no unauthorized influence is detected at these sample sizes.

All values above supersede the six withdrawn numeric claims in earlier drafts
(AUR 0.9341, UIR 0.2000, and the prior availability/overhead figures), which are
test-double artifacts and must not be reported. The present values are labeled
NOT\_CONFIRMATORY: no inferential claim is made and no confirmatory hypothesis
(H1--H10) is tested here.
