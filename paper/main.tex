\title{Authorized to See, Forbidden to Use: Purpose-Selective Bounded
Execution for Financial AI}

\begin{document}
\begin{abstract}
Financial organizations may be authorized to hold confidential attributes for
one purpose while being prohibited from using them for another. Existing
confidential-computing and agent-control mechanisms do not by themselves show
that a system preserves the attribute's approved utility while preventing its
cross-purpose influence. We define Purpose-Selective Bounded Execution (PSBE)
and FinBoundBench, a paired financial-AI protocol that measures authorized
utility, prohibited influence, cross-layer compromise, evidence reconstruction,
privacy, availability, and overhead. This review draft intentionally contains
no empirical result claim; the abstract will be completed only from frozen
confirmatory artifacts.
\end{abstract}

\keywords{financial AI, purpose limitation, confidential computing, agent
security, differential privacy, provenance}
