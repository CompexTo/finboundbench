# ICAIF-format page budget (v4 confirmatory)

The short-paper target is eight total ACM `sigconf` pages, including
references, with no supplement or appendix. Current build (2026-08-09) is
**6 pages** with zero overfull hboxes and zero undefined references.

Actual per-section usage is tracked in `paper/compiled/`; the budget below
(8.0) leaves headroom for reviewer-driven additions or an extra figure.

| Material | Target pages |
| --- | ---: |
| Abstract and introduction | 0.9 |
| Related work | 0.7 |
| Definition and threat model | 0.9 |
| Benchmark | 1.1 |
| Runtime | 0.8 |
| Experimental setup | 0.8 |
| Results | 1.7 |
| Limitations, ethics, conclusion | 0.6 |
| References | 0.5 |
| **Total** | **8.0** |

Build commands (MiKTeX portable):

```
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Figures (bound to frozen results, regenerated by scripts):
- `generated/headline-figure.pdf` — `scripts/run_v4_headline_figure.py` (frozen reports only)
- `generated/conditions-schematic.pdf` — `scripts/make_paper_figure_schematic.py`

The USENIX route will use a separate venue branch/template and may expand the
security-system and artifact material. Do not compress the ACM template or hide
required limitations to meet this budget.
