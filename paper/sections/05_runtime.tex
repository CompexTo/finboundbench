\section{PSBE-Runtime}

PSBE-Runtime is an anonymous reference implementation, not the definition of
PSBE. It constructs a deterministic approved projection, binds exact workload
and model artifacts, executes within a hardened non-TEE sandbox, mediates tools,
network routes, secrets, calls, and bytes, and holds outputs in quarantine for
native validation. Contract revision, approval, expiry, supersession, and
revocation are evidence-bearing state transitions.

The evidence bundle binds canonical contract, dataset/projection, workload,
model/route, capability decisions, privacy ledger, release decision, and event
chain. A separate verifier rebuilds hashes and mandatory-claim coverage without
trusting the runtime's summary. Missing or ambiguous evidence fails closed. The
strong B2 comparator receives an equivalent honest projection and hardened
sandbox but lacks the full purpose lifecycle and evidence contract.
